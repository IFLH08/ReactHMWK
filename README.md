## ReactHMWK

Proyecto con dos partes principales:

- `API`: backend con Express y MongoDB para autenticacion, usuarios y utilidades de seguridad.
- `react`: frontend con React y Vite para login, perfil, contenido y administracion.

### Estructura

- `API/` contiene la Rest API, scripts de hash y migracion, rutas, controladores y modelos.
- `react/` contiene la aplicacion cliente, vistas, componentes y recursos estaticos.

### Uso general

1. Instala dependencias en `API` y `react`.
2. Configura las variables de entorno necesarias para el backend.
3. Inicia el backend en `API`.
4. Inicia el frontend en `react`.
